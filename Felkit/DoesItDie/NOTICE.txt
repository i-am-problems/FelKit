Changes made for Warlock All-in-One (every Lua file states it was modified):
1. Each file starts with a provenance header and keeps DoesItDie's own
   namespace inside the add-on (S.DID instead of the add-on table).
2. Tracking.lua (DoesItDie.lua): saved data in its own variable instead of
   DoesItDieDB; chat prefix names Warlock All-in-One; no options window and no
   target frame attachment at load; the /did command is replaced by
   S.DID.command (reached with /waio did plates|debug|reset), so the
   original add-on can be installed alongside. The tracking itself is unchanged.
3. Nameplates.lua: drawn only while the Warlock All-in-One "nameplates" switch
   is on and the original DoesItDie add-on is not loaded (no double marker);
   the kill icon shows unless the mode is "marker". Unchanged otherwise.
4. The marker and kill icon (S.DID.barMarker) are also drawn on the health bars
   of the Warlock All-in-One DoT table (MultiTarget/Presentation.lua).
5. Tracking.lua (0.7.2): a DoT whose description no registered language reads
   (Italian, Portuguese, Russian, Chinese clients) falls back to the add-on's
   locale-free spell data (S.DID.spellData) for its total, school, duration and
   tick interval.
6. Tracking.lua (0.7.3): the add-on's spell data comes FIRST, in every language
   (readDot): it is the player's real total (spell power, talents, rank, DB2
   duration and tick interval), while descriptions leave spell power out.
   Descriptions stay for spells it does not know, finishers and DoTs without a
   total. Such a DoT is not "unsure"; before its first observed tick it is
   predicted and judged by that total's share per tick, not by a tick size
   learned in an earlier fight; observed ticks still take over as before.
7. 0.7.4: saved data in WarlockAllInOneDIDDB. Fewer game API calls:
   Tracking.lua stays idle while neither the DoT table bars nor the nameplates
   use it (tracked DoTs are forgotten when it turns off); the diagnostic log is
   trimmed by batches of 100 lines (up to 600 lines kept); whether a spell is a
   finisher is remembered per spell ID; combo point power events are only
   followed for rogues and druids; the empty breakdown is one shared table.
   Nameplates.lua: the 40-plate scan only runs while a DoT or cast estimate is
   tracked; widgets are hidden once; a plate's style is rebuilt only when the
   look's version (db.styleVersion, set by Glue.lua) changes.
